# Quizzy

AI-free quiz site: categories → sub-categories → quizzes → questions, plus this-day-in-history events.

## Stack

- **TanStack Start** (SSR + Nitro) on **Vite 8**, TanStack Router file routes in `src/routes`, React 19, TypeScript 5.9, Tailwind v4 (`@tailwindcss/vite`)
- **Package manager: pnpm** (single app at the repo root — there is no `apps/` monorepo)
- **Database:** PostgreSQL via **Prisma 8 (Prisma Next)**, contract-first — author `prisma/contract.prisma`, then run `pnpm prisma:contract:emit`; artifacts land in `src/generated/prisma8` (committed)
- **API layer:** oRPC router (`src/server/router.ts`) served at `/rpc` by the catch-all server route `src/routes/rpc.$.ts` (per orpc.dev/docs/adapters/tanstack-start). `client` from `src/lib/orpc.ts` is isomorphic: in-process `createRouterClient` during SSR, `RPCLink` (absolute origin URL — `RPCLink` does `new URL(url)`, relative paths throw) in the browser
- **Caching:** Redis-backed oRPC cache middleware (`src/server/cache.middleware.ts`); bypassed in dev, JSON-round-trips output on every path

## Commands

```bash
pnpm dev                    # dev server on port 3001 (3000 is another local app; needs Postgres + Redis, see .env)
pnpm build                  # vite build && tsc --noEmit (type validation — do not bypass)
pnpm start                  # run the Nitro production server (.output/server/index.mjs)
pnpm lint                   # eslint (flat config: typescript-eslint + react-hooks)
pnpm prisma:contract:emit   # regenerate src/generated/prisma8 after editing the contract
pnpm prisma:migrate         # apply migrations
node --run prisma/seed.ts   # or: pnpm exec tsx prisma/seed.ts
```

## Routing notes (TanStack Router — replaces the old Next.js App Router)

- `src/routes/__root.tsx` is the document shell (fonts, GTM, providers, navbar/footer, error/not-found). `src/routeTree.gen.ts` is generated by the Vite plugin — never edit it.
- Route **loaders** fetch through the isomorphic `client` — they run on the server for the initial request and in the browser during SPA navigation. Never put credentials in a loader directly; go through oRPC procedures (which sit behind the Redis cache middleware).
- Metadata: `head: ({ loaderData }) => ({ meta, links })` replaces `metadata`/`generateMetadata`. Loading: `pendingComponent` replaces `loading.tsx`. Missing data: `throw notFound()` from `@tanstack/react-router`.
- Server routes (`server.handlers` inside `createFileRoute`) exist for `/rpc`, `/sitemap.xml` (`sitemap[.]xml.ts`), `/robots.txt` (`robots[.]txt.ts`), `/og.png` and `/quiz/$slug/og.png` (OG cards via `takumi-js`'s `ImageResponse` — API-compatible with `next/og`; fonts are TTFs in `src/fonts/` read from `process.cwd()` at runtime, so deployments must ship that directory — see Dockerfile).
- Search params are validated per route (`validateSearch`, e.g. `/this-day-in-history?month=&day=`).
- Public env vars use the `VITE_` prefix (`VITE_BASE_URL` in `src/lib/constants.ts`), not `NEXT_PUBLIC_`.

## Prisma 8 gotchas (see `@prisma/orm-postgres/skills/prisma-8/` for the full API reference)

- Query with `db.orm.public.<Model>` (fluent: `.where((m) => m.field.eq(v)).orderBy(...).offset/.limit`, terminal `.all()`/`.first()`). Counts: `.aggregate((agg) => ({ count: agg.count() }))` — there is no bare `.count()` terminal.
- Timestamp columns decode to `Temporal.PlainDateTime`. `src/lib/prisma.ts` installs `temporal-polyfill/global` and exports `asTimestamp(date)` for writing/filtering. Never pass raw `Date` objects into queries.
- `Temporal` values cannot cross the Server → Client Component boundary — the cache middleware JSON-round-trips oRPC output for this reason; keep new procedures behind it (or return plain data).
- The contract was inferred from the live DB: `Quiz.id`, `Question.id` and `updatedAt` have **no defaults** — supply them (e.g. `randomUUID()`) on create.
- N:M relations are not supported by the ORM lane. Quiz↔Tag goes through the `QuizTag` junction relation (`quizTags` → `tag` includes), and writes create junction rows explicitly.
- Server-side result shapes are kept v7-compatible (`_count.questions`, `tags[].tag.name`) via explicit mapping in `src/server/quiz.ts` — components depend on those shapes.
- Enums (`QuizDifficulty`, `EventCategory`) live in `src/lib/enums.ts` — Prisma 8 generates no enum objects.
